## ✨ About The Project

**Puzzle Game** is a fun and interactive web-based puzzle game developed with **Vue 3**.

The project was created as a practical frontend project to work with modern Vue concepts such as **component-based architecture, state management, routing and reusable UI components**.

The goal is simple:

> 🧠 Arrange the puzzle pieces correctly and complete the image!

But the experience is designed to be more than just a simple puzzle, with **music, images, animations and an interactive interface**.

## 🚀 Getting Started

To run the project locally, follow these steps.

### 1. Clone the repository

```bash
git clone https://github.com/Ali-Git-1/Puzzle-game.git
```

### 2. Navigate to the project

```bash
cd Puzzle-game
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

---

## 🎯 How To Play

1. Start the game.
2. Choose or enter the game.
3. Puzzle pieces are shuffled.
4. Move the pieces to their correct positions.
5. Complete the image.
6. Enjoy the completion animation and sound. 🎉
